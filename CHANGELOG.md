# Changelog

## 1.0.0 - 2026-11-05

- Ship an original bitmask/MRV Sudoku solver and unique symmetric puzzle generator.
- Add easy, medium, hard, expert, deterministic generation, and shell solver modes.
- Add a responsive terminal game with rich pencil grids, conflicts, matching-value highlights, undo, notes, and hints.
- Freeze solved boards and persist independently ranked best solves per difficulty.
- Add strict local checks, dual-remote release, and native Cargo installation.
